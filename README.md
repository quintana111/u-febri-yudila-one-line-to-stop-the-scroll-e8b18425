One line of text, at most 200 characters, that makes a stranger stop
scrolling and smile. Plain text, no code, no assets.

## Run

```sh
node main.ts
```

## Files

- `output/entry.txt` — the entry line (single line, ≤ 200 characters)
- `main.ts` — Node 22, stdlib only; validates the entry (non-empty, ≤ 200
  chars, single line), writes it to `output/entry.txt`, verifies a
  byte-identical round-trip, and prints it
- `candidates.txt` — the 5 candidate one-liners composed for this bounty,
  with character counts
